# Versions

Snapshots of each published demo, so nothing is lost when the design moves on. `prototype/index.html` is always the current version. Older demo versions are kept here as files.

| Version | File | What changed |
|---|---|---|
| v1 | (palette only, see PALETTES.md) | First canvas: cool graphite, followed system light/dark |
| v2 | (palette only, see PALETTES.md) | Magnetic connecting, People nodes, topic-gravity clusters |
| v3 | v3-sequencer-dark.html | Dark sequencer style, single connection point, floating edges, Tidy |
| v4 | v4-shadcn-chrome.html | shadcn-style controls (tabs, badges, buttons, switch) over the editorial canvas |
| v5 | v5-v1-graphite-dark.html | v4 UI with the v1 cool-graphite dark palette and saturated topic colours; saved maps migrate their topic colours |
| v6 | v6-filters-popover.html | Filters as a mega-menu popover anchored to its button (caret, three columns, active-count badge), sliders icon |
| v7 | v7-two-ports-header.html | Two typed connection points (● continuity, ◆ reference), standalone entries, centred view tabs, Filters/Tidy on the canvas, Data + mode top right |

The v1 and v2 HTML files were overwritten before snapshots were kept. Their exact colour values are recorded in PALETTES.md, and the published artifact keeps its own version history (versions 1–4).
